# 점심메이트 🍱

직원들의 오늘 제외 카테고리를 모아 남은 음식점 중 한 곳을 공평하게 추첨하는 웹사이트입니다. HTML/CSS/JavaScript만 사용하며, 설치할 라이브러리나 데이터베이스가 없습니다.

## 사용하기

1. 이름 또는 닉네임으로 팀원을 추가합니다. 처음에는 `나`가 등록되어 있습니다.
2. 각 팀원이 오늘 피하고 싶은 카테고리를 선택합니다. 주황색으로 표시되면 **제외** 상태입니다.
3. 한 명이라도 제외한 카테고리는 모든 음식점 후보에서 빠집니다.
4. **점심 메뉴 돌리기**를 누릅니다. 후보가 0곳이면 버튼이 비활성화되고, 1곳이면 남은 곳으로 결정합니다.
5. 추첨 결과나 음식점 카드를 누르면 등록한 음식점 링크가 새 창에서 열립니다.

제외 선택은 **한국 시간 자정**에 초기화됩니다. 팀원 이름과 음식점 목록은 유지합니다. 추첨 중 목록이나 제외 선택을 바꾸면 진행 중인 추첨은 취소됩니다.

## 직원끼리 공유하는 방식

이 사이트는 서버/DB가 없는 정적 웹사이트입니다.

- 음식점 추가·삭제와 팀원별 선택은 **현재 브라우저의 localStorage**에 저장됩니다.
- **현재 목록과 오늘 선택 공유하기**로 그 시점의 음식점 목록과 팀원별 선택이 담긴 링크를 만듭니다. 동료는 링크를 열고 **가져오기**를 눌러 자신의 브라우저 목록을 교체할 수 있습니다.
- 공유 링크는 **스냅샷**이며 자동 동기화되지 않습니다. 각자 선택한 후 새 링크를 이어서 전달하거나, 한 화면에서 모두의 선택을 입력해 주세요. 여러 링크의 내용을 자동으로 합치지는 않습니다.
- 같은 브라우저에서 연 탭끼리는 변경 내용을 동기화합니다.
- 공유 링크에는 입력한 이름과 선택이 담깁니다. 닉네임 사용을 권장합니다. 과거 날짜의 링크는 음식점과 팀원만 가져오고 제외 선택은 비웁니다.
- 모든 직원이 접속 즉시 같은 목록을 보게 하려면 아래 방법으로 GitHub 기본 목록을 수정하세요. 기기 간 실시간 공동 편집에는 별도 DB가 필요합니다.

## 기본 음식점 변경

저장소의 [`restaurants.js`](./restaurants.js)를 수정하면 GitHub Actions가 재배포합니다.

```js
export const DEFAULT_RESTAURANTS = [
  { id: 'ssepiri', name: '쎕이리', category: '쌀국수', url: 'https://naver.me/53lKMMIt' },
  { id: 'popeyes', name: '파파이스', category: '햄버거', url: 'https://naver.me/FLyTDJYa' },
  { id: 'seodamheon', name: '서담헌', category: '중식', url: 'https://naver.me/5iTOwwcj' },
];
```

각 음식점의 `id`는 고유하고 일정하게 유지해 주세요. 같은 `category`를 사용하면 같은 제외 항목으로 묶입니다. 설정에서 **목록 파일 다운로드**를 누르면 현재 목록으로 만든 `restaurants.js`를 받을 수 있습니다. 이 파일을 저장소에서 교체해도 됩니다.

기본 목록이 업데이트되면 기존 브라우저의 개인 추가·삭제를 유지하면서 기본 음식점의 변경 사항을 반영합니다. 브라우저에서 따로 삭제한 기본 음식점은 되살리지 않습니다. 저장 공간을 지우면 최신 기본 목록으로 시작합니다.

## GitHub Pages 배포

1. `heerachoi/randomFoodPicker` 공개 저장소의 `main` 브랜치에 소스를 올립니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
3. **Actions → Deploy lunch picker to GitHub Pages → Run workflow**로 최초 배포합니다. 이후 `main`에 수정 내용을 push하면 테스트, 빌드, 배포가 자동 실행됩니다.
4. 성공한 workflow의 `github-pages` 배포 링크로 접속합니다. 프로젝트 주소는 `https://heerachoi.github.io/randomFoodPicker/`입니다.

모든 파일 경로는 상대 경로이므로 GitHub Pages 프로젝트 하위 경로에서도 작동합니다. `.github/workflows/deploy.yml`은 `dist/`만 배포하므로 테스트 파일이나 설명 문서는 웹 배포물에 포함되지 않습니다.

## 로컬 실행 및 검증

Node.js 24와 Python 3을 사용합니다. `npm install`은 필요하지 않습니다.

```sh
npm run dev
# http://127.0.0.1:4173

npm test
npm run build
```

ES 모듈을 사용하므로 `index.html`을 파일로 직접 여는 대신 HTTP 서버에서 실행하세요. Google Fonts를 사용할 수 없으면 시스템 글꼴로 표시됩니다.
